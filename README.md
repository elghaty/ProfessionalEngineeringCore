# Electrical Engineering Pro

Professional Android electrical design and calculation platform.

## Engineering Architecture

The application uses one logical engineering core:

ProfessionalEngineeringCore

The core is modular internally and delegates calculations to specialized engineering calculators.

### Core Modules

- Load Calculator
- Cable Calculator
- Breaker Calculator
- Voltage Drop Calculator
- Transformer Calculator
- Generator Calculator
- Motor Calculator
- Pump Calculator
- Short Circuit Calculator
- Protection Calculator

## Design Principles

1. One source of truth for engineering calculations.
2. No engineering formulas inside UI screens.
3. Independent calculators for maintainability.
4. Typed engineering models.
5. Unit-aware calculations.
6. Project-based design workflow.
7. Automatic design recommendations.
8. User override capability.
9. Persistent project database.
10. Automated engineering tests.
